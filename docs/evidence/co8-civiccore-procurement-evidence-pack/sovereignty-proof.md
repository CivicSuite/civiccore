## Interpretation

Provisioning and live release verification necessarily contact GitHub,
PyPI/files.pythonhosted.org, and Sigstore endpoints. That is allowed during
the setup and verification phase.

The runtime proof is different: once dependencies and release artifacts are in
the cleanroom, the CivicCore smoke path and offline release-provenance fixtures
run with Docker networking disabled. That proves the default library runtime
path exercised by the smoke does not require outbound network access.

## Limit

This proof covers CivicCore's default library runtime smoke and offline fixture
verification. It does not claim that optional downstream live connectors,
optional cloud LLM providers, or future module-specific services are offline.
Those paths must be proved in the downstream module evidence packs.
